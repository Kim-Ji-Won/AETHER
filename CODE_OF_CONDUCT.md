# Code of Conduct

AETHER adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) standards, scope and graduated enforcement guidelines by reference. Participants should communicate respectfully, welcome different perspectives, accept feedback and protect others' privacy. Harassment, discrimination, threats and disclosure of private information are unacceptable.

## Project administration

The repository maintainer is responsible for moderation; there is no separate staffed enforcement team or guaranteed response time. Depending on severity, responses may include correction, warning, temporary restriction or permanent exclusion, with context and proportionality considered.

## Reporting limitation

A project-private conduct reporting channel is pending. Do not post sensitive incident details publicly. Use GitHub's “Report abuse” controls for platform abuse. For routine, non-sensitive moderation requests, identify the relevant public discussion without repeating harmful content. Private Vulnerability Reporting, if enabled later, is for software vulnerabilities, not general conduct reports. The maintainer must establish a suitable private conduct route before promising confidential case handling.

This adoption links the standard rather than reproducing it; local reporting limitations above are explicit.
