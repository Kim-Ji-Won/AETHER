# Architecture evidence

No production architecture is accepted. Current candidates are Tauri/React, Rust with Swift native integration, TypeScript orchestration, OpenAI Responses/Realtime, SQLite, Playwright and Three.js/R3F. Runtime placement (WebView versus sidecar), native bridging, permissions and distribution require controlled experiments.

Architecture investigations must reference a real research Issue and record objective, options, exact environment/version, experiment boundaries, success/failure criteria, observed evidence, limitations and follow-up ADR. Label claims OBSERVED, DOCUMENTED, INFERRED, UNKNOWN or BLOCKED. Do not copy private host inventories, paths or credentials into public evidence.

Use [decision records](../decisions/README.md) for choices. API availability, OS permission, distribution eligibility and success in a signed build are four separate claims. P0-B experiments remain unauthorized until their specific scope is approved.
